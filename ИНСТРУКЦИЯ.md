# Как выложить викторины в интернет (GitHub + Render)

После этого игроки подключаются с любого интернета — свой Wi‑Fi или мобильная сеть, локальная сеть не нужна.
Обе викторины живут на одном сайте:

| | Игроки | Ведущий (проектор) |
|---|---|---|
| Финансовая | `https://ВАШ-САЙТ.onrender.com/finance` | `…/finance/host` |
| РУДН | `https://ВАШ-САЙТ.onrender.com/rudn` | `…/rudn/host` |

---

## Шаг 1. Загрузить файлы на GitHub (≈5 минут)

1. Зайдите на https://github.com и войдите (или зарегистрируйтесь).
2. Справа вверху **«+» → New repository**.
   - Repository name: например `quizzes`
   - Можно оставить **Public** или выбрать **Private** — Render работает с обоими.
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **«uploading an existing file»**.
4. Откройте папку `викторины` на рабочем столе и **перетащите в окно браузера** эти файлы и папку:
   - `server.js`
   - `quizzes.js`
   - `package.json`
   - папку `public` целиком (в ней 5 файлов)

   Файлы `.bat`, `.gitignore` и эту инструкцию загружать не обязательно.
5. Внизу нажмите **Commit changes**.

Проверьте: в репозитории должны быть `server.js`, `quizzes.js`, `package.json` и папка `public`.

## Шаг 2. Запустить на Render (≈5 минут)

1. Зайдите на https://render.com → **Get Started** → войдите **через GitHub** (GitHub попросит разрешить доступ — разрешите).
2. Нажмите **New → Web Service**.
3. Выберите свой репозиторий `quizzes` (если его нет в списке — нажмите «Configure account» и дайте Render доступ к нему).
4. Заполните настройки:
   - **Name:** например `rudn-quiz` — из него получится адрес `rudn-quiz.onrender.com`
   - **Language / Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** **Free**
5. Ниже, в **Environment Variables**, нажмите **Add Environment Variable**:
   - **Key:** `HOST_PASSWORD`
   - **Value:** придумайте пароль ведущего (его будете вводить только вы)
6. Нажмите **Deploy Web Service**. Через 1–3 минуты вверху появится адрес вида `https://rudn-quiz.onrender.com` и статус **Live**.

> Без `HOST_PASSWORD` экран ведущего на Render не откроется — это защита, чтобы игроки не могли переключать вопросы.

## Шаг 3. Проверить

1. Откройте `https://ВАШ-САЙТ.onrender.com/rudn/host` на ноутбуке → введите пароль ведущего.
2. Отсканируйте QR-код телефоном **с мобильного интернета** (выключите Wi‑Fi) → введите имя → оно должно появиться на экране ведущего.
3. Нажмите «Начать викторину», ответьте с телефона — всё работает.
4. Чтобы сбросить тестовую игру: «Завершить досрочно» → «Новая игра».

## В день мероприятия

- **Откройте экран ведущего за 3–5 минут до начала.** Бесплатный Render «засыпает», если сайтом никто не пользовался 15 минут; первое открытие тогда занимает около минуты. Пока экран ведущего открыт, сервер не уснёт.
- **Не меняйте файлы на GitHub во время игры** — Render перезапустит сервер, и текущая игра со всеми очками обнулится.
- Если игрок случайно закрыл страницу — пусть откроет ссылку снова, он вернётся со своими очками.
- Обе викторины можно проводить хоть одновременно — у каждой своя игра.

## Как поменять вопросы

На GitHub откройте `quizzes.js` → значок карандаша (Edit) → исправьте → **Commit changes**.
Render сам перезапустит сайт через 1–2 минуты.
`answer` — номер правильного варианта, считая с нуля: `0` = А, `1` = Б, `2` = В, `3` = Г.

## Запуск без интернета (как раньше, в одной Wi‑Fi сети)

Двойной щелчок по `Запустить финансовую викторину.bat` или `Запустить викторину РУДН.bat`.
Пароль в этом режиме не нужен: экран ведущего открывается только на самом ноутбуке.
Если телефоны не подключаются — один раз запустите `Разрешить подключение телефонов.bat` от имени администратора.
